# Circuit Simulation Assistant v0.1.0

Run user-authored LTspice schematics through explicit Review / Approve / Run,
then extract measurements from RAW data with deterministic Python analysis.

## Highlights

- ASC upload and rule-based natural-language requests.
- AC, Transient, DC Sweep and single R/C Parameter Sweep with comparative results.
- Structured Analysis Summary, AC reference and target trace suggestions.
- Source ASC preservation; Windows portable build and installer.

## Install

Planned asset: **CircuitSimulationAssistant-Setup.exe** (87,193,866 bytes).
Once this release is published:

1. Download the installer from Assets and compare the SHA-256 below.
2. Run Setup and launch Circuit Simulation Assistant.
3. Install **LTspice separately** for simulation, then restart the app.
4. Upload an `.asc`, enter your request, review/edit and approve before Run.

Windows-focused release; validation used Windows 11 x64. The installer bundles
the Python runtime required by the application, so a separate Python installation
is not expected for normal use. Keep the launcher console open; Ctrl+C stops it.

## Validation

- **174 tests passed** in Prompt 015A; earlier actual LTspice AC/Transient/DC/Parameter
  integrations are documented in the repository.
- Packaged/installed exe startup and actual AC divider: 10 Hz–1 MHz,
  **-6.020599913279624 dB**, RAW/LOG, graph, Summary and source preservation.
- Developer-host install/uninstall/reinstall, shortcuts, current-user/default and
  custom paths, non-admin execution and **127.0.0.1-only** listener verified.

Validation was on a **development Windows 11 Home 25H2 machine**.
**Clean Windows VM validation without Python installed has not yet been performed.**

## Known Limitations

- **Unsigned installer; Windows may display a SmartScreen warning.**
- LTspice is external; actual clean-VM LTspice installation transition is pending.
- Optional AI interpretation architecture exists, but actual OpenAI API smoke
  testing has not been performed. The core bundle omits the optional OpenAI SDK.
- Complex/custom schematics may need manual trace/reference selection.
- Administrator/interactive installer cases, SmartScreen/firewall behavior and
  offline operation remain unverified. Defender protection was disabled on the test host.
- One 15-second shutdown timeout occurred; a repeat passed with a 45-second allowance.
  Redact user paths from local simulation logs before sharing.

Full evidence, build provenance and pending cases are in `docs/releases/v0.1.0.md`
and `docs/release-checklist.md` in the repository.
