# Circuit Simulation Assistant v0.1.0

Published on **2026-10-01 at 04:49:34 UTC** as the latest release, not a draft or
prerelease. The [GitHub Release](https://github.com/minsu727/circuit-simulation-assistant/releases/tag/v0.1.0)
uses the existing tag `v0.1.0` at `75f6db47f722b20241190275ce01611ac00f2d1c`.
See the [publication verification record](README.md).
Circuit Simulation Assistant runs user-authored LTspice schematics after explicit
review and approval, then measures RAW results with deterministic Python analysis.

## Highlights

- LTspice `.asc` upload and rule-based natural-language simulation requests.
- Explicit **Review → Approve → Run** flow; simulation uses a copy of the source ASC.
- AC gain and -3 dB bandwidth; Transient waveforms and applicable time-domain metrics;
  DC Sweep with requested-point interpolation.
- Single R/C Parameter Sweep with comparative measurements and failed-point reporting.
- Deterministic result extraction and structured **Analysis Summary**.
- AC reference and target trace suggestions requiring user selection/approval.
- Windows portable build and Windows installer, with optional Desktop shortcut.

Optional AI interpretation architecture is included in the project, but actual
OpenAI API smoke testing has not yet been performed. The core Windows bundle
omits the optional OpenAI SDK; this is not a validated production AI feature.

## Requirements

- Windows; the recorded validation environment is Windows 11 x64.
- **LTspice installed separately** for simulation. The installer does not include
  or download LTspice, and does not accept its license on the user's behalf.
- The installer bundles the Python runtime required by the application, so a
  separate Python installation is not expected for normal use. The clean Windows
  VM limitation above still applies.

## Download

Download **[CircuitSimulationAssistant-Setup.exe](https://github.com/minsu727/circuit-simulation-assistant/releases/download/v0.1.0/CircuitSimulationAssistant-Setup.exe)**
(87,193,866 bytes), or open the
[v0.1.0 Release page](https://github.com/minsu727/circuit-simulation-assistant/releases/tag/v0.1.0).
The public download returned HTTP 200 and its bytes matched the SHA-256 below.

The portable folder can also be built from source, but a portable ZIP is not an
asset prepared here. Source archives are not the compiled Windows application.

Installation:

1. Download `CircuitSimulationAssistant-Setup.exe` from the release's Assets.
2. Compare its SHA-256 below, then run the installer and choose the install scope/path.
3. Launch Circuit Simulation Assistant from the installed shortcut.
4. Install LTspice separately if simulation is needed, then restart the app.
5. Upload your `.asc` schematic and enter a simulation request.
6. Review/edit the conditions, approve them, and select Run Simulation.

Keep the launcher console open while using the browser. Stop it with Ctrl+C
before uninstalling; closing the browser tab alone does not stop the server.

Unsigned installer; Windows may display a SmartScreen warning.

## Known Limitations

- Installer is **unsigned**; Windows may display a SmartScreen warning.
- **Clean Windows VM validation is pending**, including Python absence and actual
  LTspice absent → installed transition. Host missing-dependency checks used a
  child-process configuration override.
- LTspice must be installed separately. This is a Windows-focused release;
  other OS/architecture configurations are not claimed as tested.
- Actual OpenAI API smoke testing has not been performed; the optional SDK is
  excluded from the core Windows bundle.
- Complex/custom LTspice schematics may require manual trace/reference selection;
  external model/include upload handling remains limited.
- Administrator Program Files installation, interactive final-launch checkbox,
  SmartScreen/firewall dialogs and complete offline behavior are not validated.
  Defender protection was disabled on the validation host; no AV certification is claimed.
- One initial AC smoke exceeded a 15-second shutdown wait. The repeat passed with
  a 45-second allowance and normal exit; shutdown latency on other machines is pending.
- Local simulation diagnostics may contain user data paths; redact logs before sharing.
  Physical AC–Transient/DC–Transient cross-validation is still pending.
